一步一步：负偏移分支

查看完整计算过程
  1. 读懂题设：beq 位于 0x00400020，目标 0x00400010；需要求 16 位立即数字段。
  2. 定位基准：分支基准为 PC+4=0x00400024。
  3. 计算字节差：目标 − 基准 = 0x00400010 − 0x00400024 = −20 B。
  4. 换算指令字偏移：−20 / 4 = −5，16 位补码是 0xFFFB。
  5. 反代验证：符号扩展 0xFFFB 得 −5，再左移 2 得 −20；0x00400024−20=0x00400010。

试算：8 位运算、标志与跳转

用 AL／BL 的 8 位模型观察同一位模式的两种解释。输入范围 −128～255；非负数也可写成 0x00～0xFF。

完整例子：CMP AL,BL 后为何 JA 与 JL 可以同时成立？
  1. AL=0xFF、BL=1：无符号解释为 255 和 1，有符号解释为 −1 和 1。
  2. 8 位相减得到 0xFE：CF=0、ZF=0、SF=1、OF=0，两个操作数保持不变。
  3. JA 要求 CF=0 且 ZF=0，因此满足无符号“大于”。
  4. JL 要求 SF≠OF，因此也满足有符号“小于”。这两种解释并不矛盾。

特殊结构与图

特殊矩阵的压缩存储对称矩阵只存一个三角区；三角矩阵还需统一存放非三角区的相同常量；三对角矩阵只存主对角线及相邻两条对角线。查漏要点

核心结论

对称矩阵只存一个三角区；三角矩阵还需统一存放非三角区的相同常量；三对角矩阵只存主对角线及相邻两条对角线。

条件与过程

先明确下标从 0 还是 1 开始、按行还是按列、元素字节数和首地址，再数排在目标元素之前的元素。

例子

1 起始下标、按行存下三角（含对角线）：A[i,j] 的 0 起始序号为 i(i−1)/2+j−1（i≥j）；对称矩阵 i<j 时交换 i、j。三对角矩阵按行压缩、下标从 1 开始时，带内元素 0 起始序号为 2i+j−3，共存 3n−2 个元素。

辨析边界

稀疏矩阵三元组不支持按普通二维数组公式直接随机定位；压缩存储并不总保留随机存取能力。

辨析边界

核心结论

线索标志用于区分孩子指针和遍历前驱／后继线索；必须先确定采用哪一种遍历。

条件与过程

中序线索树：若右指针为线索，它直接指向后继；若为右孩子，后继是右子树沿左孩子到达的最左结点。

例子

中序序列为 D B E A C，则 B 的后继是 E。左指针为孩子时，前驱是左子树中的最右结点。

辨析边界

中序线索树找后继方便，不代表先序／后序线索树的每一种前驱后继都能用相同步骤得到。

核心结论

用左孩子、右兄弟表示法：左指针连第一个孩子，右指针连下一个兄弟。

条件与过程

树的先根遍历对应二叉树先序，树的后根遍历对应二叉树中序；森林先序对应二叉树先序，森林中序对应二叉树中序。
