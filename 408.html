408 记忆与概念补充

错误认识

高度公式中的 n 是结点数；m 是最少孩子数。

定义与正确结论

非空 m 阶 B 树（m≥3），m 为最大孩子数；n 为关键字总数，h 为含关键字结点的层数，根为第 1 层，a=⌈m/2⌉。

原理、适用条件与辨析

同一高度下，填满得到最大关键字数，稀疏得到最小关键字数。由两端反解 h，并按整数高度取整。空的失败结点不计入 h；空树另行约定。

简短例子

m=5、h=3：最少 2×3²−1=17 个关键字，最多 5³−1=124 个。n=17 时只能 h=2 或 3；不是唯一高度。

错误认识

定义与正确结论

关键字互异时，先序+中序或后序+中序可唯一恢复二叉树；先序+后序一般不能。

原理、适用条件与辨析

先序首元素/后序末元素确定根，中序根位置分左右子树。重复标签可能破坏唯一性；只有一个孩子时先后序不能分辨它在左还是右。

int partition(int a[], int low, int high) {
    int pivot = a[low];
    while (low < high) {
        while (low < high && a[high] >= pivot) --high;
        a[low] = a[high];
        while (low < high && a[low] <= pivot) ++low;
        a[high] = a[low];
