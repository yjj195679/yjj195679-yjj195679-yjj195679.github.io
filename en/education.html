Research method

Define, then verify

Start from the observation model and assumptions, derive executable updates, then test the implementation and conclusion with minimal cases and controlled experiments.

Validation pipeline

From model to evidence

Each step produces something inspectable: an equation, an update rule, a test case, or a controlled comparison.

01 · Model

Specify the observation model

Write y = Hx + n, then fix the operator H, boundary conditions, noise distribution, tensor shapes, and numerical ranges. Do not compare algorithms while the model is ambiguous.

02 · Derive

Obtain executable updates

Derive gradients, proximal maps, or projections from the objective, checking dimensions, signs, step-size conditions, and invertibility. Every mathematical term should map to code.

03 · Test

Start with minimal cases

Use an identity operator, zero noise, one small image, and a fixed random seed to separate mathematical errors, data errors, and memory failures.

04 · Evaluate

Compare under controls

Fix the data split, degradation kernel, noise, random seed, and metrics before comparing a baseline with a change; retain the configuration, logs, checkpoints, and runtime environment.
