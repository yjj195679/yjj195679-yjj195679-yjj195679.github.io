01 · Super-resolution

DPSR reproduction

The goal is to use one trained super-resolution network with different blur kernels. PnP-ADMM updates the degradation-model constraint separately from the SRResNet prior.

Implementation

Training and degradation modeling

Training uses DIV2K high-resolution images with online Gaussian, motion, and disk blur kernels, followed by convolution and Bicubic downsampling. SRResNet has 16 residual blocks and is optimized with L1 loss and Adam.

DIV2KSRResNetL1 LossAdam
Inference

PnP-ADMM inference

Inference alternates updates for data consistency, the SRResNet prior, and the dual variable. The blur kernel enters the data-consistency step, so changing the kernel does not require training another network.

Data consistencyPlug-and-PlayArbitrary kernels
Engineering

8 GB memory adaptation

When full-image inference exceeded GPU memory, I split the input into tiles and stitched the outputs. I also standardized input normalization, kernel format, and device selection to prevent test-time interface mismatches.

Result

Training and inference results

Completed training, checkpointing, test-image inference, and result comparisons. Training L1 loss decreased from about 0.089 to 0.033, and the retained checkpoint is sr_epoch_197.pth.

02 · Optimization

Primal–Dual deblurring

The data-fidelity term keeps the reconstructed image consistent with the blurred observation, while total variation suppresses noise and preserves major edges. Chambolle–Pock iterations solve the resulting objective.

Model
The objective contains a quadratic data-fidelity term and a TV regularizer: the first matches the reblurred reconstruction to the observation, while the second suppresses noise and preserves major edges.
Dual update
The dual variable associated with the image gradient first takes an ascent step and is then projected onto the norm ball set by the regularization parameter λ.
Primal update
The primal update requires a linear solve. Under periodic boundary conditions, convolution is diagonal in the Fourier domain, so the update can be computed directly with FFTs.
Experiment focus
Step-size conditions, kernel alignment, boundary artifacts, noise level, and regularization balance.

03 · Deep restoration

UNet / Restormer

This section records UNet and Restormer training and explains the causes and fixes for NaNs, color shifts, and GPU-memory failures.

Stability

NaN and color-shift diagnosis

After checking data loading, model inputs, and loss computation, I standardized tensor ranges and channel order, eliminating NaNs and color shifts caused by inconsistent normalization.

Memory

Memory and resolution trade-offs

I reduced training memory with cropping and smaller batches, disabled gradients during validation, and used tiled inference for full images so the models could run on approximately 8 GB of GPU memory.

Architecture

Restormer training

Trained Restormer on about 700 sharp/blurred image pairs, compared validation results after each epoch, and saved the best checkpoint as best_restormer.pth.

Hybrid

Optimization-based post-processing

Used deep-network output as the input to Primal–Dual post-processing, then compared sharpness, noise, color stability, and runtime to decide whether the extra optimization step was useful.

Conclusions & limits

What is complete, what remains

The current results establish whether an implementation runs and whether a failure has been diagnosed. I do not compare methods without results obtained under the same test conditions.

DPSR

The pipeline runs; evaluation remains limited

The falling training loss, saved checkpoint, and test-image inference show that the implementation pipeline runs. Current tests use zero added noise and do not yet cover multiple kernels and noise levels on one benchmark, so they do not establish superiority over other SR methods.

Primal–Dual

A baseline exists; parameters need comparison

The two Cameraman results verify the basic iteration and frequency-domain solve. Because they use Gaussian blur and have not been systematically tuned, they are implementation baselines rather than the method’s best performance.

UNet / Restormer

Failures are diagnosed; comparison needs one protocol

The experiments confirm how normalization and memory handling affect stability, and the best Restormer checkpoint has been saved. The models have not yet been evaluated with identical degradations, splits, and metrics, so this section reports engineering findings only.
