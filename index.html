设计目标

先把网站本身做好

内容可以逐步补充，基础体验必须从一开始就清晰、统一并且可靠。

低依赖

静态核心

主要页面不依赖构建工具即可运行，结构、样式与交互边界清楚，便于维护和迁移。

可扩展

内容与界面分层

项目、学习、成果与生活均使用统一内容框架，后续补充资料时无需重新设计页面。

核心功能

围绕阅读与访问设计

功能不是装饰，而是帮助访问者更快定位页面、调整阅读方式并完成互动。

导航系统

多页面、双语与快捷检索

主导航、页内导航、当前位置高亮和键盘检索共同覆盖不同访问路径。
阅读体验

主题、响应式与阅读工具

支持跟随系统的明暗模式，并适配桌面、平板、手机以及打印输出。
互动服务

天气与公开留言

天气按需请求定位；留言板提供发布、展示与受保护的管理流程。
实现方式

从结构到发布

各层职责独立：HTML 负责语义，CSS 管理视觉系统，JavaScript 提供渐进增强，外部服务只承担必要的数据能力。

HTML

语义化多页面结构

中英文页面一一对应，保留清楚的标题层级、锚点、替代入口与搜索引擎元数据。

CSS

统一设计变量与断点

颜色、字体、间距、圆角和栅格由同一套变量控制，明暗主题和各尺寸布局共享规则。

JavaScript

渐进式交互增强

菜单、搜索、章节定位、阅读模式和动效建立在可直接阅读的页面之上，并兼顾键盘与减少动态效果设置。

Services

GitHub Pages 与 Supabase

静态资源由 GitHub Pages 发布；留言数据与管理员验证由 Supabase 提供，避免把敏感凭据放入前端。
